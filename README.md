# ✊✋✌ Jokenpô - Pedra, Papel e Tesoura

Um programa em Python que permite você jogar **Pedra, Papel e Tesoura** contra o computador com resultado animado e estilizado.

---

## 💰 Funcionalidades

- Jogar **Pedra**, **Papel** ou **Tesoura** contra o computador  
- Contagem animada "JO-KEN-PO"  
- Resultado em cores:
  - 🟢 Verde → Vitória
  - 🟡 Amarelo → Empate
  - 🔴 Vermelho → Entrada inválida  
- Computador escolhe aleatoriamente a jogada  
- Interface simples via console
